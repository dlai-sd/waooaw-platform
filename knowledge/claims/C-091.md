Claim ID:        C-091
Type:            OBLIGATION
Statement:       Every cost incurred by WAOOAW in delivering any service to any customer —
                 whether charged to the customer, absorbed by WAOOAW, or shared as platform
                 overhead — must have a corresponding entry in the Thread Catalog before that
                 cost may be incurred. The Thread Catalog is the single authoritative record
                 of all cost-generating activities on the WAOOAW platform. A cost that occurs
                 without a Thread Catalog entry is an unaccounted institutional liability. Upon
                 discovery of any such cost, the WAOOAW Billing Engine automatically generates
                 a Founder Action for Thread Catalog registration. The undocumented cost
                 continues to accrue — but no new customer may be onboarded to any agent that
                 relies on the undocumented thread until the Thread Catalog entry is
                 Founder-authorized. Thread Catalog entries require Founder Action for creation,
                 modification of cost parameters, and deprecation. No agent specification,
                 architectural decision, or autonomous sprint may introduce a new billable
                 thread without a corresponding Founder-authorized Thread Catalog entry.
Confidence:      100%
Source:          GOAL-004 brainstorming session 2026-07-30. The fundamental problem identified:
                 WAOOAW has no canonical record of what it pays to providers. FA-012 through
                 FA-015 in FOUNDER-ACTION.md (Kling AI, HeyGen, ElevenLabs, Runway ML) are
                 pending Founder actions — these are WAOOAW's own provider subscriptions that
                 are not tracked in any system. Without a Thread Catalog, WAOOAW cannot:
                 (a) calculate margin per customer, (b) detect cost overruns before they
                 compound, (c) project procurement needs, (d) enforce the minimum margin
                 floor (C-089). The Thread Catalog is the data foundation for everything else
                 in GOAL-004. C-091 makes it constitutionally mandatory.
Depends On:      C-089 (Minimum Margin Floor — computed from Thread Catalog costs),
                 C-088 (Agent Billing Profile — references Thread Catalog entries for each
                 thread the agent consumes), C-051 (Resource Transparency — what WAOOAW
                 charges must trace to what WAOOAW costs)
Produces:        institutional.thread_catalog table (Founder-authorized rows; status =
                 ACTIVE / DEPRECATED / PENDING_FOUNDER_AUTH); WBE rejects any request to
                 serve a thread not in thread_catalog with status = ACTIVE; automatic Founder
                 Action generated when WBE detects a cost hit against an unregistered thread;
                 FOUNDER-ACTION.md updated automatically with new FA-NNN entries for
                 unregistered threads discovered at runtime; monthly Thread Catalog audit
                 report produced by Platform Operations agent.
Contradicted By: NONE. Urgency, competitive pressure, or sprint deadlines do not authorize
                 incurring costs outside the Thread Catalog. An agent that requires an
                 undocumented thread is not deployable until the thread is cataloged and
                 Founder-authorized. This is the cost equivalent of C-088 (agent not
                 publishable without Billing Profile): no thread, no service.
Status:          RATIFIED — 2026-07-30 (Founder: Yogesh Khandge — GOAL-004 spec phase)
Reviewer Notes:  The Thread Catalog entry requires Founder Action specifically because cost
                 decisions change the institution's financial baseline. Sujay (Business Growth)
                 has Tier 1 authorization for many operational decisions, but thread cost
                 registration is Tier 0 — Founder only. This is the same tier as platform_phase
                 changes and minimum margin adjustments (C-089).

                 The "no new customers" gate (rather than "stop all current customers") is
                 intentional. It avoids disrupting existing customers whose agents depend on
                 the undocumented thread while the Founder Action is completed. Existing
                 service continues; expansion is blocked.

                 Thread Catalog entries must track: provider name, unit of measure, raw cost
                 in INR (with FX source date), markup %, marked-up cost, FX buffer %, last
                 review date, and deprecation policy. The FX buffer % is set at the thread
                 level — different providers have different FX risk profiles (USD-billed
                 providers need a larger buffer than INR-billed providers).

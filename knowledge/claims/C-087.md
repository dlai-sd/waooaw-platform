Claim ID:        C-087
Type:            OBLIGATION + PLATFORM_INTEGRITY
Statement:       Any fix, enhancement, or optimization applied to the autonomous
                 sprint pipeline MUST be designed for generic sprint execution —
                 not only for the sprint currently in progress. This applies to
                 every office that touches scripts/, .github/workflows/, or any
                 pipeline component.

                 BEFORE implementing a pipeline change, the implementing office MUST:

                 1. IDENTIFY THE GENERIC PATTERN: name at least one other sprint
                    type (greenfield, defect/enhancement, tech debt, agent spec update)
                    that would trigger the same failure pattern under the same conditions.
                    If only the current sprint triggers it, the fix is a band-aid, not
                    a solution.

                 2. VERIFY WITH REGISTRY DATA: check logs/failure-registry.jsonl.
                    A single entry (one run, one file) is anecdotal evidence, not a
                    pattern. Three or more entries across different run_ids for the
                    same error_codes family = confirmed pattern eligible for a fix.
                    Fewer than three: raise a Constitutional Blocker — request more
                    runs or use cases before applying a fix.

                 3. IMPLEMENT GENERICALLY: the fix must address the root cause in
                    the generator (prompt construction, context injection, retry
                    advisor) — not in the generated output. Editing a generated file
                    directly is never a constitutional fix. Editing the generator
                    that produced the bad file is.

                 4. STOP IF DATA IS INSUFFICIENT: if the implementing office cannot
                    demonstrate generic applicability (Step 1) OR lacks registry
                    evidence (Step 2), it MUST raise a Constitutional Blocker and
                    wait. "We need one more sprint run to confirm the pattern" is
                    a legitimate blocker. Proceeding without evidence is not.

                 Scope: applies to all pipeline components:
                   scripts/autonomous_sprint_runner.py
                   scripts/task_decomposer.py

                   .github/workflows/autonomous-sprint.yaml

                   src/ files (C-059 governs those)

Claim ID:        C-096
Type:            OBLIGATION + PLATFORM_INTEGRITY
Statement:       Before any sprint task executes in the autonomous pipeline, the
                 dependency chain of the service being extended MUST be verified
                 clean. Specifically: all existing Python source files in the
                 service's src/ directory must compile without SyntaxError, and
                 all tasks marked "done" in the Work Contract task table must have
                 produced real output files (not skeleton stubs). This is enforced
                 by scripts/check_import_chain.py as a blocking pre-flight gate.

                 A broken foundation (prior sprint left behind uncompilable code,
                 or a "done" task never actually wrote its output files) makes
                 every subsequent sprint task produce code that imports broken
                 modules — the new sprint's tests will fail for reasons unrelated
                 to the new code. The failure report is misleading and wastes
                 the retry budget. C-096 prevents this: no sprint task may begin
                 on top of a broken foundation.

                 Implementation: scripts/check_import_chain.py must return exit 0
                 before the runner executes any task. Exit 1 increments FAILURES
                 and blocks the sprint. Missing output files for "done" tasks emit
                 a warning (non-blocking) but are recorded for Founder review.

                 This claim extends C-059 (Traceability): "done" in the WC task
                 table MEANS the output files exist and are syntactically valid
                 on the current main branch. A "done" task whose output file does
                 not exist is a traceability violation.

Confidence:      98%

                 but markup/models.py, bundle_engine.py, router.py absent from main.
                 WC027-02 (test writing) would have imported non-existent code,
                 producing LLM hallucination of module interfaces.
                 Local execution evidence (2026-07-31): check_import_chain.py

Claim ID:        C-100
Type:            SECURITY_OBLIGATION

Statement:       Every WAOOAW HTTP service MUST configure CORS according to the
                 following two rules:

                 Rule 1 — Wildcard origin and credentials are mutually exclusive:
                 If allow_origins contains "*", allow_credentials MUST be False.
                 Combining wildcard origin with allow_credentials=True allows any
                 malicious website to make authenticated cross-origin requests
                 using a customer's live session. This is an OWASP A05:2021
                 Security Misconfiguration that exposes customers to CSRF attacks.

                 Rule 2 — When credentials are permitted, origins must be explicit:
                 If allow_credentials=True, allow_origins MUST be an explicit
                 allowlist of known WAOOAW domains. It MUST NOT contain "*".

                 Rule 3 — Method and header scope:
                 allow_methods and allow_headers MUST be restricted to the subset
                 the service actually handles. Wildcard allow_methods=["*"] and
                 allow_headers=["*"] are prohibited.

Rationale:       The autonomous code generation pipeline (LLMs) consistently
                 produces permissive default CORS configurations as scaffolding
                 boilerplate. Without an explicit constitutional prohibition,
                 this vulnerability re-appears in every generated service.

                 This was discovered in WC-027 post-sprint audit: billing-engine
                 main.py was generated with allow_origins=["*"] AND
                 allow_credentials=True — a direct OWASP A05:2021 violation that
                 would have shipped to production without this claim.

                 Constitutional chain:
                 - C-002 (Trust through Evidence): a service that exposes customer
                   sessions to arbitrary third-party sites cannot be trusted.
                 - C-035 (Decision Space Boundaries): the agent must not take
                   actions (CORS configuration) that expand attack surface beyond
                   what the architecture specifies.
                 - OWASP Top 10: A05:2021 Security Misconfiguration.

Enforcement:     1. LLM SYSTEM prompt: the CORS forbidden pattern is injected
                    into every Python code generation prompt via
                    _PYTHON_FORBIDDEN_PATTERNS in context_builder.py.
                    Pattern text: "⛔ [C-100] NEVER combine allow_origins=['*']
                    with allow_credentials=True — OWASP A05 CSRF vector."

                 2. Constitutional Compliance Test CCT-CORS-01 (pending —
                    to be added in next CCT sprint):
                    Scan every *.py file in src/ for the pattern
                    'allow_origins=["*"]' co-occurring with
                    'allow_credentials=True'.

                 3. Pre-flight preflight gate (manual for now): the constitutional
                    auditor checks every new FastAPI app instantiation for
                    CORSMiddleware compliance.

Example — VIOLATION (prohibited):
                 app.add_middleware(
                     CORSMiddleware,
                     allow_origins=["*"],        # wildcard
                     allow_credentials=True,     # credentials — C-100 violation
                 )

Example — COMPLIANT (credentials disabled with wildcard):
                 app.add_middleware(
                     CORSMiddleware,
                     allow_origins=["*"],
                     allow_credentials=False,    # C-100 compliant
                     allow_methods=["GET", "POST"],
                     allow_headers=["Content-Type", "Authorization"],
                 )

Example — COMPLIANT (credentials enabled with explicit allowlist):
                 app.add_middleware(
                     CORSMiddleware,
                     allow_origins=["https://app.waooaw.ai", "https://waooaw.ai"],
                     allow_credentials=True,     # C-100 compliant — explicit origins
                     allow_methods=["GET", "POST"],
                     allow_headers=["Content-Type", "Authorization"],
                 )
